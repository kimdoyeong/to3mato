# To3mato 웹 데모

빌드 없이 실행되는 HTML/CSS/JavaScript 데모입니다.

## 실행

```sh
python3 -m http.server 4173 --directory dist --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:4173 을 엽니다.

## 핵심 동작

- 왼쪽: 할 일 / 프로젝트 / 캘린더 / 설정
- 오른쪽: 타이머 / 액션 버튼 / 오늘 할 일
- 작업 전환 시 기존 기록을 0 / 0.5 / 1포모도로로 반올림하고 새 타이머 시작
- 일시정지 시간을 제외한 실제 집중 시간 보관
- 브라우저 저장 및 기록 JSON 내보내기
- 설정에서 10초 집중 및 5초 휴식으로 빠르게 체험 가능

## 디자인

- `dist/style.css`: 기본 레이아웃과 동작에 필요한 스타일
- `dist/theme.css`: 따뜻한 손글씨 테마. `style.css` 뒤에 불러와 색, 글꼴, 모양을 덮어씁니다. `index.html`에서 이 파일의 `<link>`를 빼면 이전 디자인으로 돌아갑니다.
- 글꼴: 제목은 감자꽃(Gamja Flower), 본문은 푸어스토리(Poor Story)입니다. 감자꽃은 숫자 `0`이 `o`처럼 보여서 숫자 0~9만 푸어스토리로 바꿔 끼웁니다(`dist/fonts/poor-story-digits.woff2`, 1.4KB). 두 글꼴은 Google Fonts의 SIL Open Font License 글꼴입니다.
- 두 글꼴 모두 굵기가 하나뿐이라 `font-synthesis: none`으로 가짜 굵게를 막았습니다.
- 타이머 숫자는 칸을 고정해서 숫자가 바뀌어도 시계가 흔들리지 않습니다.

## 검증

```sh
node --test core.test.mjs
```

## 데모의 범위

샘플 작업은 첫 실행 날짜를 기준으로 생성됩니다. 데이터는 브라우저에 저장되며 계정 동기화는 없습니다. 프로젝트 생성과 휴식 전환 및 설정 화면의 기록 배치는 데모를 위한 제안입니다. 캘린더에서는 작업에 날짜 하나를 지정할 수 있고 한 작업의 포모도로를 여러 날짜로 나누는 기능은 후속 설계가 필요합니다.
