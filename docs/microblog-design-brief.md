# Claude 디자인 작업 요청

상태: 전달 자료 준비 완료. 2026-11-08 로컬 Claude Code가 미로그인 상태여서 실제 디자인 작업은 시작되지 않았다.

마이크로블로그 디자인 담당은 Claude다. 현재는 기획과 디자인 단계다. 아래 자료와 확정된 동작을 바탕으로 검토 가능한 디자인 시안을 작성한다.

## 작업 전 읽을 자료

1. 저장소 루트의 `MEMORY.md`와 `AGENTS.md`
2. `docs/microblog-plan.md`
3. `docs/product-plan.md`의 제품 방향과 문체
4. `src/styles/tokens.css`, `src/styles/components.css`의 기존 디자인 체계
5. `src/components/FocusLog.svelte`, `src/components/DiaryView.svelte`, `src/components/Ticket.svelte`, `src/App.svelte`의 기존 화면 구조

## 담당 범위와 산출물

다른 에이전트도 같은 저장소에서 작업 중이다. 다른 사람의 변경을 되돌리지 말고 최신 파일에 맞춰 작업한다. Claude가 생성하거나 수정할 파일은 아래 두 개로 한정한다.

- `docs/microblog-design.md`: 화면 구성, 상태별 동작 표현, 반응형 구성, 기존 토큰과의 연결, 미정 사항을 적은 한국어 디자인 명세 초안
- `docs/design/microblog-preview.html`: 브라우저에서 열 수 있는 디자인 시안. 데스크톱과 모바일의 공개 프로필, 집중 로그의 공개 범위 설정, 상단 공유 메뉴를 확인할 수 있게 한다. 외부 서비스나 실제 데이터를 연결하지 않는 로컬 정적 시안으로 작성한다. 새 이미지 생성이나 외부 이미지 사용은 필요하지 않다.

앱 소스, DB, 기획서, MEMORY.md, AGENTS.md는 수정하지 않는다. 커밋, 푸시, 배포는 수행하지 않는다. 비밀 파일이나 인증 정보를 읽지 않는다. 결과 보고에는 산출물 경로와 미정 사항만 간결히 적는다.

## 시안에 포함할 화면과 상태

### 공개 프로필

- 글 작성 기능 없이 포모도로 활동을 보여준다.
- GitHub 잔디와 같은 날짜별 활동 표시와 오늘 완료한 포모도로 수가 공통 정보다.
- 이부끄 씨의 모든 선택 항목 OFF 상태에서는 공통 정보만 보인다.
- 김토마토 씨의 모든 선택 항목 ON 상태에서는 공통 정보에 선택 공개 항목이 추가된다.
- 열람자 계정, 댓글, 좋아요, 팔로우는 없다.
- 인스타그램 프로필에서 방문하는 모바일 사용 흐름을 고려한다.

### 공개 범위 설정

- 집중 로그 탭 안에 설정 섹션을 둔다.
- 섹션의 `공유 프로필`은 사용자 가칭이다. 최종 이름으로 확정하지 않는다.
- 항목마다 ON/OFF를 설정한다. 모두 OFF해도 공개 프로필에는 잔디와 오늘 완료한 포모도로 수가 남는다.
- 개별 항목 목록과 초기값은 아직 미정이다. 프로젝트 정보, 완료한 할 일, 집중 시간, 티켓 메모는 검토 중인 후보이며 확정 사항으로 표시하지 않는다.
- 실제 스위치 초기값이 확정된 것처럼 표현하지 말고 시안에서 두 사용자 상태를 구별한다.

### 영상 배경

- 3초 영상은 주간 영상에 통합한다. 별도의 3초 영상 공개 항목을 두지 않는다.
- 공개를 원하는 사용자에 한해 최신 한 주 분량의 주간 영상만 배경으로 표시한다.
- 영상 공개가 켜져 있으면 매주 최신 주간 영상으로 자동 교체한다. 주차 선택 UI를 두지 않는다.
- 영상 목록, 개별 영상 게시물, 지난 영상 보관함을 공개 프로필에 두지 않는다.
- 실제 영상 파일 대신 배경 영역을 시각적으로 표시해도 된다. 대체 배경, 재생 방식, 움직임 설정은 디자인 제안으로 구분한다.

### 공유 메뉴

- 앱 상단 `공유하기` → `프로필 공유하기` → 프로필 링크 복사 흐름이다.
- 실제 공유 링크나 하위 도메인은 아직 정하지 않았다. 로컬 시안에서는 네트워크 요청이나 실제 클립보드 변경 없이 위치와 흐름을 표현한다.

## 카피와 미정 사항

- 사용자가 직접 정한 `공유하기`, `프로필 공유하기`는 그대로 사용한다. `공유 프로필`은 가칭으로 취급한다.
- 기존 문구는 원문을 유지한다. 새 카피, 슬로건, 안내 문장, 장식 라벨과 캡션을 임의로 추가하지 않는다.
- 화면에 꼭 필요한 최소 기능 명칭 외에 새 문구가 필요하면 시안에 넣지 말고 디자인 명세의 승인 필요 목록에 제안한다.
- 검토 중인 항목을 시안에서 예시로 쓰면 명세에서 제안임을 명시한다. 사용자의 결정을 대신하지 않는다.
- 표시 이름, 사진, 잔디 집계 기준과 기간, 최초 공개 동작, 활동 기록 갱신, 공개 중지, 플랫폼 제공 순서는 미정이다. 디자인 편의상 가정한 값은 명세에서 가정으로 분리한다.
- 기존 앱의 색, 종이 표면, 서체와 컴포넌트를 살펴 디자인한다. 디자인 선택은 Claude가 제안하고 해당 근거를 명세에 적는다.

작업 완료 후 두 산출물의 경로와 남은 결정 사항을 보고한다.
