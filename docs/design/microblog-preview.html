✕주소 미정⋯

공개 프로필 검토 메모

  1. 1상단 배경. 모든 사용자에게 있다. 주간 영상 ON이면 영상(시안은 색 면 4개를 3초마다 교체), OFF이거나 새 영상이 없는 주에는 단색 그라데이션이다. 그라데이션은 아래 6종 중 공개 프로필 ID의 해시로 하나를 고른다(파란 테두리가 현재 사용자). 시안 ID는 김토마토 씨 pf_8c2e1a, 이부끄 씨 pf_3b7d90. 그라데이션 배경에는 정지 버튼이 없다. 일시 정지 버튼과 움직임 줄이기 대응은 제안이다.
  2. 2표시 이름과 사진. 첫 공유 때 입력한 값이다. 사진은 선택이라 김토마토 씨는 사진 있음, 이부끄 씨는 사진 없음으로 둔다. 사진은 색 면으로 대신한다.
  3. 3공통 정보. 오늘 완료한 포모도로 수. 숫자와 토마토 도장을 함께 쓴다.
  4. 4공통 정보. 잔디. 최근 20주, 월요일 시작, 완료 포모도로 수 5단계는 디자인 가정이다. 오늘 칸은 형광펜 테두리로 표시한다.
  5. 5선택 공개 후보 예시: 집중 시간, 프로젝트, 완료한 할 일, 티켓 메모. 항목 이름과 목록은 확정이 아니다.

✕주소 미정⋯

공개 범위 설정 검토 메모

  1. 1섹션 제목 공유 프로필은 사용자 가칭이다. 최종 이름은 미정.
  2. 2항상 공개되는 공통 정보. 스위치 대신 자물쇠로 표시해 끌 수 없음을 보여준다.
  3. 3주간 영상. 공개 여부를 사용자가 선택하는 항목으로 확정됐다. 주차 선택 UI는 두지 않는다.
  4. 4검토 중인 후보 항목. 이름, 목록, 순서, 초기값은 미정이다. 시안의 ON/OFF는 두 사용자의 상태를 구별하기 위한 값이다.
  5. 5티켓 메모는 완료한 할 일에 딸린 정보로 가정해 들여 쓴다. 완료한 할 일이 OFF면 비활성화된다. 제안.
  6. 6표시 이름과 사진. 첫 공유 때 입력한 값을 보여주고 수정으로 바꾼다. 수정 대화상자에서도 사진을 추가하거나 삭제한다. 이 화면은 첫 공유를 마친 상태다. 첫 공유 전에는 값 자리에 없음을 두고 수정 버튼을 숨기는 것을 제안한다. 이 행의 위치도 제안이다.

스위치를 직접 눌러 오른쪽 미리보기와 공개 프로필 화면에 반영되는지 확인할 수 있다.

Mac 앱 · 작업 영역 상단

공유 메뉴 검토 메모

  1. 1공유하기. 작업 영역 상단 날짜 왼쪽에 둔다. 모든 탭에서 같은 위치다.
  2. 2프로필 공유하기. 누르면 메뉴가 닫히고 링크가 복사된다. 시안에서는 실제 클립보드를 바꾸지 않는다.
  3. 3복사 결과 알림. 기존 알림 부품을 쓴다. 실패 시에는 링크를 복사하지 못했습니다. 다시 시도하세요.를 같은 위치에 보여준다.
  4. 4첫 공유 때만 표시 이름을 입력받는다. 최대 20자, 다른 사용자와 같은 이름 허용(사용자 결정). 제목은 사용자가 정한 프로필 공유하기를 그대로 쓴다.
  5. 5저장을 누르면 이름, 사진, 공개 범위를 저장하고 링크를 복사한 뒤 알림을 보여준다. 닫기나 Esc는 공유하지 않고 닫는다. 빈 이름이면 기존 오류 형식으로 안내한다.
  6. 6사진은 선택이다. JPEG, PNG, HEIC, WebP, 10MB 이하. 가운데 정사각형으로 자동으로 잘라 원형으로 보여준다. 시안은 실제 사진 대신 색 면으로 표시하고 파일 선택 창을 열지 않는다.
  7. 7공개 범위. 집중 로그 탭의 공유 프로필 카드와 같은 항목과 값이다. 여기서 바꾸면 카드에도 반영되고, 닫기나 Esc로 공유를 취소하면 대화상자를 열기 전 값으로 되돌린다.
  8. 8미리보기. 입력한 이름, 사진, 공개 범위를 모바일 공개 프로필 배치로 바로 보여준다.

지금은 두 사용자 모두 첫 공유 전 상태다. 프로필 공유하기를 누르면 첫 공유 대화상자가 열리고, 저장한 뒤에는 바로 링크가 복사된다. 공개 중지 위치와 iPhone 배치는 미정이라 표시하지 않았다.
