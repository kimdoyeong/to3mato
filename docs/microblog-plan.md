# To3mato 마이크로블로그 기획

작성일: 2026-11-08
상태: 기획 중. 공유 흐름과 항목별 공개 설정 방식을 정했으며 공개 항목 목록과 상세 동작은 후속 논의에서 결정한다.

디자인 담당: Claude. 작업 범위와 제약은 `microblog-design-brief.md`를 따른다.

## 목적

사용자가 포모도로 활동을 공개 프로필로 보여주고 그 링크를 인스타그램 프로필 등에 올릴 수 있게 한다. 별도의 글 작성 기능은 두지 않는다.

## 확정된 범위

- GitHub의 잔디처럼 날짜별 활동을 보여준다.
- 공개 프로필에는 잔디와 오늘 완료한 포모도로 수를 공통으로 표시한다.
- 집중 로그 탭에서 추가로 공개할 항목을 각각 ON/OFF로 설정한다. 설정 섹션의 `공유 프로필`은 가칭이다.
- 3초 영상 공개는 주간 영상에 통합한다. 주간 영상은 원하는 사용자에 한해 최신 한 주 분량만 공개하고 프로필의 배경으로만 사용한다. 매주 최신 주간 영상으로 자동 교체한다.
- 앱 상단의 `공유하기`에서 `프로필 공유하기`를 누르면 프로필 링크가 복사된다.
- 링크를 받은 사람은 웹에서 프로필을 읽는다. 열람자 계정은 필요하지 않다.
- 댓글, 좋아요, 팔로우는 두지 않는다.
- 공개 프로필은 제품 사이트와 다른 하위 도메인에서 제공한다. 하위 도메인 이름은 미정이다.

## 사용자 흐름

### 프로필 링크 공유

1. 사용자가 To3mato로 계획하고 포모도로를 완료한다.
2. 자신의 활동을 보여주기 위해 앱 상단의 `공유하기`를 누른다.
3. `프로필 공유하기`를 누른다.
4. 프로필 링크가 클립보드에 복사된다.
5. 인스타그램 프로필 등 원하는 위치에 링크를 붙여 넣는다.
6. 방문자는 링크를 열어 잔디와 공개된 활동을 확인한다.

공개 범위는 집중 로그 탭에서 설정한다. 첫 공유 전 설정을 안내할지와 표시 이름을 어떻게 정할지는 아직 결정하지 않았다.

### 공개 범위 설정

1. 사용자가 집중 로그 탭으로 이동한다.
2. `공유 프로필`(가칭) 섹션에서 공개 범위 항목을 확인한다.
3. 각 항목의 ON/OFF를 설정한다.
4. 공개 프로필에는 공통 항목과 사용자가 ON한 항목이 표시된다.

| 사용자 | 설정 | 공개 프로필 |
| --- | --- | --- |
| 김토마토 씨 | 항목을 각각 모두 ON | 잔디, 오늘 완료한 포모도로 수와 선택 가능한 모든 추가 항목 |
| 이부끄 씨 | 항목을 모두 OFF | 잔디와 오늘 완료한 포모도로 수만 표시 |

공개 범위 항목을 모두 OFF해도 프로필 링크는 열리고 공통 항목을 볼 수 있다. 프로필 공유 자체를 중지하는 동작은 별도로 정한다. 각 항목의 초기값과 일괄 설정 기능의 제공 여부는 미정이다.

### 주간 영상 공개

- 3초 영상은 주간 영상에 통합하며 개별 영상 공개 항목을 두지 않는다.
- 주간 영상 공개는 사용자가 선택한다.
- 공개할 수 있는 영상은 한 주 분량으로 제한한다.
- 공개한 주간 영상은 프로필 배경으로만 사용한다. 공개 프로필에 영상 목록이나 개별 영상 게시물을 두지 않는다.
- 주간 영상 공개가 켜져 있으면 매주 최신 주간 영상으로 배경을 자동 교체한다. 공개 프로필에는 최신 한 주 분량만 표시한다.

## 공개 프로필 초안

위에서 정한 공통 항목과 공개 설정 방식을 바탕으로 상세 구성을 제안한다. 아래의 미정 항목과 추가 구성은 확정 범위에 포함하지 않는다. 화면 문구도 별도로 정한다.

| 항목 | 제안 | 정할 내용 |
| --- | --- | --- |
| 사용자 식별 | 공개용 표시 이름 | 이름 설정 위치와 프로필 사진 포함 여부 |
| 잔디 | 하루의 포모도로 활동량을 색 농도로 표시 | 완료 포모도로 수 또는 실제 집중 시간, 표시 기간, 날짜 기준 |
| 활동 요약 | 오늘 완료한 포모도로 수는 공통 표시 | 기간별 합계, 집중 시간과 연속 활동 일수의 추가 여부 |
| 활동 상세 | 항목별 ON/OFF로 공개 범위 선택 | 프로젝트명, 할 일 제목, 티켓 메모 등 구체적인 항목 목록 |
| 배경 영상 | 원하는 사용자만 최신 한 주 분량의 주간 영상을 공개하고 매주 자동 교체 | 새 영상이 없는 주의 처리와 배경 재생 방식 |
| 공유 주소 | 프로필에 계속 사용할 수 있는 고정 링크 | 주소 형식, 변경과 공유 해제 후 재활성화 방식 |

## 다음에 정할 동작

1. 공개 항목: 개별 스위치로 제어할 항목 목록과 각 항목의 초기값.
2. 집계 규칙: 0.5포모도로와 중단한 집중 기록의 반영, 하루를 나누는 시간대.
3. 최초 공유: 공개 미리보기와 설정을 어느 단계에서 제공할지.
4. 갱신: 공유 후 새 활동을 자동 반영할지, 사용자가 다시 게시할지.
5. 공유 관리: 공개 중지, 재공개, 원본 기록 삭제와 계정 삭제의 반영.
6. 플랫폼: Mac과 iPhone의 제공 순서와 상단 버튼 위치.
7. 배경 영상: 새 영상이 없는 주의 처리와 배경 재생 방식.

## 기존 도메인 계획의 기준

`docs/domain-migration.md`의 공유 페이지 기준을 따른다.

- 별도 Pages 프로젝트 또는 Worker로 운영하고 쿠키를 두지 않는다.
- 링크 미리보기용 HTML 메타 태그를 서버에서 생성한다.
- 기본 `noindex`를 적용한다.
- 공유 링크를 끄면 404를 반환하고 캐시를 비운다.
- 악용 신고 연락처를 제공한다.
- 공개 페이지 제공 전에 개인정보처리방침에 해당 내용을 반영한다.

앱 구현, 서버 설계와 배포는 이 기획 단계에서 진행하지 않는다.
